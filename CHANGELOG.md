# Changelog

## 0.1.0

- Colours each part of a line like the sticky it becomes, with colours of
  your own in Settings | Editor | Color Scheme | estorm
- Parse errors and lint warnings, highlights of the event under the caret,
  completion, go to definition and rename, from estorm's language server
  (estorm 0.21), bundled and run on Node.js 20 or later
- Live preview of the board beside the text, with click-to-line, pan and
  zoom
- Line comments with `#`, and matching brackets
